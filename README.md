# 人物动作帧技能 · Hanmo Sprite Walk

这是从《幻想三国传》人物帧制作经验中整理的 Codex 技能公开版，适用于像素风 RPG 角色站姿、行走和跑步动作的制作、修订与检查。

提供从角色参考图、方向母图、生成动作、检查切帧，到透明 PNG、图集与动态预览的工作流程。着重检查角色身份、手脚交替、循环衔接、颜色一致和透明残边。

## 安装

将 [hanmo-sprite-walk](hanmo-sprite-walk/) 文件夹复制到 `~/.codex/skills/hanmo-sprite-walk/`，再重新打开 Codex。也可以对 Codex 说：

```text
从这个 GitHub 仓库安装 hanmo-sprite-walk 技能。
```

使用示例：

```text
用 $hanmo-sprite-walk，根据这张人物图制作四方向行走动画，每个方向六张活动帧，并给我一个能逐帧查看的预览。
```

## 运行条件与边界

- 需要 Python 3 和 Pillow；查看各脚本的 `--help` 获取参数。
- 生成人物新姿势需要当前 Codex 环境提供可用的图像生成能力。工具的使用限制、额度或费用以实际环境为准。
- 附带脚本用于任务记录、按实测网格收编、结构检查及生成预览；脚本不会画出新动作，也不能自动判定动作自然。
- 此公开版不包含《幻想三国传》的私人角色图、游戏工程和历史图片。使用者提供自己的角色参考图；脚本的 96×96、六活动帧等默认值应按项目需求核对。
- 结构检查、逐帧观察、播放检查、用户认可及游戏接入需分别记录。

技能入口见 [SKILL.md](hanmo-sprite-walk/SKILL.md)，辅助脚本位于 [scripts](hanmo-sprite-walk/scripts/)。
