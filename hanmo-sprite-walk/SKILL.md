# 人物动作帧

根据用户提供的角色参考和目标项目制作可审阅的动画候选。先确认画风、方向、动作、画布、帧数、锚点和已有认可素材；用户指定的要求优先。仅要求总结或检查时，保持在对应范围内。

## 制作流程

1. 观察原图，区分人物身份参考与动作参考，记录角色的脸、头发、服装、装备侧别、轮廓和比例。修复旧动画时先记录好帧及其哈希，只改用户指出的问题。
2. 每个方向准备可用的同角色自然站姿母图。左右方向分别制作与检查；不要把镜像直接当成最终结果。原图未展示的背面细节属于补绘，需要说明。
3. 使用当前环境可用的图像生成工具制作真实姿势。先确定两半步的承重与摆动，再补经过和过渡；走路与跑步分别处理，不能只把走路加速称为跑步。保留实际提示、参考图用途、返回原图和生成记录。收费服务需遵循用户授权。
4. 看实际返图后测量格子、间距、轮廓和顺序，再切帧。不要假设模型一定按提示画出等距网格；相邻人物粘连、跨格或缺损时先修源图。整组使用共同画布和锚点，不逐帧按包围盒缩放、居中或调整脚底。
5. 逐帧追踪左右腿与对侧手臂、肩肘腕和髋膝踝的连续变化，并检查末帧回到首帧。核对头颈肩连接、腰胯、服装、装备侧别、颜色光向和透明残边；合理遮挡不要求每帧都露出两只手。
6. 输出透明 PNG、动作图集、联系图及可暂停、逐帧、切换方向并可观察移动的预览。原尺寸和整数倍检查；站姿与活动循环的编号应对用户清楚。旧素材按原契约保留，不擅自删帧或替换已认可帧。

## 辅助脚本

脚本需要 Python 3 与 Pillow。先用 `--help` 确认当前参数：

```sh
python3 scripts/sprite_workflow.py --help
python3 scripts/review_walk.py --help
python3 scripts/verify_frame_protection.py --help
```

`sprite_workflow.py` 提供任务初始化、登记母图、按实测映射收编、生成图集和 HTML 预览。其既定工作流围绕 96×96 与六活动帧；项目规格不同时先核对脚本的具体限制，不要把它当万能切帧器。图像生成需要另行调用可用的图像工具，脚本本身不生图。

`review_walk.py` 检查尺寸、透明通道、图集对应、重复帧和可疑漂移，输出审阅材料；其默认约定需按 `--help` 和实际素材核实。`verify_frame_protection.py` 用于对照受保护的原始像素和帧。脚本提示是人工复查线索，不能自动证明自然步态或美术合格。

## 交付

分别说明：生成情况、结构检查、逐帧观察、预览连续播放、用户认可、实际引擎接入。缺方向或有不确定动作时明确列出；不要将候选、历史认可或机械检查冒充当前用户验收。
